# 增加的功能
在原本功能的基础上 **增加** 了下述功能：

- 增加支持对非图片附件的右键菜单操作
- 当以相对路径的形式插入时，去掉默认的 `./`，即从 `[](./附件名称)` 更改为 `[](附件名称)`
- 图片点击放大预览，可使用滚轮再进行调节和使用鼠标进行拖动平移，并且该功能在设置中是可以独立进行开启和关闭的，设置的名称是 **enableImageClickZoom** ，默认是开启的。
- 原版只能通过粘贴或者拖入附件，可以正常的进行链接转换和压缩。不能通过命令面板插入附件。已解决该问题，问题的原因如下：

	插件只监听 editor-drop 和 editor-paste 两个事件，而 Obsidian 的「命令面板插入附件」走的是 vault.createBinary() 直接建文件的路径，根本不触发这两个事件，所以插件完全没有机会介入。你看到的"拖入可以、命令面板插入不行"是必然结果，不是 Obsidian 版本回归。

	| 环节 | 拖入（文件管理器→编辑器） | 命令面板「插入附件」(Insert attachment) |
	| --- | --- | --- |
	| Obsidian 内部动作 | 把文件复制进库 → **触发 `editor-drop` 事件** | 打开系统文件选择器 → `vault.createBinary()` 复制到默认附件位置 → 光标处插链接 |
	| 插件能否拦截 | ✅ 能，`handleDrop` 里 `preventDefault()` 后接管：重命名→压缩→自己插链接 | ❌ 不能。无任何事件可监听（Obsidian 官方论坛开发者已确认："There is no such an event"，只能靠 `vault.on('create')` 兜底） |
	| 谁负责插入链接 | 插件 | Obsidian 自己（已插入后插件才可能知道） |


Ob 本身对视频可以双击进行放大预览。
